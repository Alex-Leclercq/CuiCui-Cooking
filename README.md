# CuiCui Cooking 🐦🍳

**CuiCui Cooking** est une application pensée pour mon téléphone. Elle me sert à garder avec moi, partout, les recettes de cuisine que j'aime.

## Ce que fait l'application

- **Mon carnet de recettes de poche :** je liste et consulte mes recettes préférées où que je sois.
- **Import par photo :** je prends en photo une recette trouvée dans un livre ou sur un site internet, et l'application en extrait automatiquement les informations essentielles :
  - le nom de la recette ;
  - les ingrédients et leurs quantités ;
  - les étapes de préparation ;
  - le temps de préparation et le temps de cuisson ;
  - le nombre de personnes ;
  - le chef ou l'auteur ;
  - la source : le livre d'origine ou le site internet.

## Principes du projet

- **Léger :** une application simple, rapide, sans superflu.
- **Sans base de données :** les recettes sont stockées dans de simples fichiers (par exemple JSON ou Markdown) directement sur le téléphone ou dans ce dépôt.
- **Mobile d'abord :** l'interface est conçue avant tout pour un usage sur téléphone.
